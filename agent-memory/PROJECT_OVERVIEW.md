# Project Overview

ZakatChain is a Web2 + Web3 platform for transparent zakat distribution, evidence review, audit records, monitoring, public verification, and geographic analysis. It must distinguish submitted information, reviewed evidence, on-chain hash registration, trusted payment confirmation, and actual real-world receipt. Blockchain inclusion proves hash anchoring only, not the physical truth of distribution.
